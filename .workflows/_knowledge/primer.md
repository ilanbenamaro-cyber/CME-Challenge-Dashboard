# Primer

Personal risk dashboard for a CME futures challenge. Phone-first. Data: Databento hourly bars, CME margins/
settlements/challenge results (scraped by Actions), the trade log from a Google Sheet via Apps Script.
Key invariants: no orders/CQG; unknown ≠ 0; rules only from plan/RULES.md; integer-cents money.
Start at plan/PLAN.md.
